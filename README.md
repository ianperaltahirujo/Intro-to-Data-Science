# Intro to Data Science

A portfolio of Jupyter notebooks documenting technical progression through core introductory data science concepts from coursework at Penn State. From probability and simulation to spatial analysis and machine learning.

## Prerequisites

- **Google Colab** — all notebooks are designed to run in a browser-based Colab environment; no local Python installation required
- **Google Drive** — notebooks may read/write data files via Drive mounting (`drive.mount('/content/drive')`)
- **Python 3** with standard data science libraries: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scipy`, `scikit-learn`, `folium` / `geopandas` (Colab provides most of these out of the box)
